# Talaan

Talaan's own web page: https://marliemarksolares-hue.github.io/Talaan/

This repository holds only a small loader (`index.html`). It opens Talaan from its Google Apps Script web app
without using the browser's Google sign-in, so Talaan opens the same whatever Google accounts the browser has.
Talaan's code (Code.gs, Index.html) and all data stay in Google Apps Script and Google Sheets. Updating Talaan
there (Deploy → Manage deployments → Edit → New version) needs no change here.
